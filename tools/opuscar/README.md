# Lemo-Opuscar films (code-only, no video model)
Engine: github.com/lemomo-ai/lemo-opuscar (MIT). Each folder here is one film's project folder; copy it into a clone of
the engine as films/<name>/ and run its build.sh. Fonts: EMS single-line SVG fonts come from the npm package
hersheytext@2.0.0 (svg_fonts/); EMSDelight and EMSCasualHand are aliased to EMSReadability and EMSAllure.
Chalk foley is synthesized (foley/lib) because the Wikimedia recordings are not reachable from the cloud box.
- psalm91-chalk: Psalm 91 KJV (verses 1, 2, 4, 11, 15), Chalkboard style, 51 s, 1920x1080 30 fps, Kokoro am_michael. First test Nov 2 2026.
